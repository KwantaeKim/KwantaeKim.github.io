After <b>cdl_gen</b> for Cadence Virtuoso, we open-source <a href="https://github.com/KwantaeKim/cirfig_gen" target="_blank" class="pub-hover"><i class="fa-brands fa-github"></i> cirfig_gen</a>, which lets a coding agent draw clean analog schematics for paper figures and presentation slides. <br>

It comes with a fixed palette of <b>49</b> hand-drawn symbols. You can simply ask Claude Code or Codex to draw the circuit you want. Each output is a single SVG, so you can fine-tune it in Visio or PowerPoint.
